Quantum-safe migration lab

Compare a conventional RSA signature with a post-quantum migration pathway.

Educational limitation: this standalone HTML demo can create and verify a real RSA-PSS signature using your browser's Web Crypto API. It does not include a standardized post-quantum cryptography library, so the PQC side is a workflow placeholder—not a real ML-DSA / SLH-DSA signature and not evidence of quantum resistance.
